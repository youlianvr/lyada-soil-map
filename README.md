# Ляда — почвенная карта

Интерактивная карта почвенных контуров окрестностей деревни Ляда
(Мостовский район, Гродненская область). Практическая часть
исследовательской работы «От карты почв — к умному урожаю».

## Страницы

- `index.html` — карта: 21 почвенный контур, цветом показана категория почвы
  (A — сухой песок, B — песок временно избыточно увлажнённый). По клику на
  контур открывается карточка участка: класс почвы, площадь, координаты,
  характеристика и рекомендации по использованию такого участка.
  Есть поиск, легенда и переключение подложки (схема или спутник).
- `research.html` — классификация контуров, таблица категорий и схема
  почвенного разреза.

## Как открыть

Страницы читают `data/zis-soil-derived.geojson`, поэтому нужен локальный
сервер (через `file://` браузер заблокирует запрос):

```
python -m http.server 8000
```

и затем `http://127.0.0.1:8000/index.html`.

## Как это сделано

Чистый HTML, CSS и JavaScript без сборки. Карта построена на Leaflet
(в `vendor/leaflet`), шрифты подключены локально, подложка — OpenStreetMap
и спутниковые тайлы Esri.

## Данные

`data/zis-soil-derived.geojson` — 21 контур: идентификатор, класс почвы,
официальное название класса, площадь и координаты. Классы почв и площади
используются картой напрямую, поэтому выгрузка содержит только их.

Рекомендации по категориям участков лежат отдельно — в
`js/agro-recommendations.js`. Это текст практической части работы
(глава 3), вынесенный в данные, чтобы карточка участка собиралась
без правок разметки.
